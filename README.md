# 📦 Inventory & Order Management System

A full-stack, containerized Inventory Command Center built with React and FastAPI. This system is designed for high efficiency, featuring real-time data filtering, inline editing, and atomic database transactions.

**Live Demo Frontend:** https://inventory-command-center.onrender.com
